Four-Tier Role Navigation & Provisioning Isolation (REQ-12, REQ-17, PROT-32)

  • 1. Operator Run: Line execution only. Standard operators view live part counters, camera feeds, and shift Golden Sample challenges. Zero tools visible. High-impact changes require 4-Eyes Supervisor Approval.
  • 2. Supervisor: Customer senior person (V. Patel). Manages scheduling, recipe assignment, pending operator approvals queue, Golden Sample audit log, and Upstream Cavity Pareto heatmaps.
  • 3. Service (Support): Dedicated to field service engineers & remote support team. Unlocked via dynamic Daily Rolling OTP (REQ-14). Hardware calibration, focus verification, strobe trims, and remote assistance via support.sundaramtech.com. Service team CANNOT alter factory hardware build settings.
  • 4. OEM Factory (Build): Used exclusively while manufacturing the machine at Sundaram factory. Unlocked via Factory Provisioning Key / Dongle. Used for physical hardware selection (camera brand, PLC model, strobe controller), software features selection & entitlements, and one-time hardcoding. NOT available to service team.

Remote Support via support.sundaramtech.com & DB Security (REQ-11, 15, 16)

  • Active Operator Screen (Never Blank): When an engineer works remotely via support.sundaramtech.com, the line monitor does NOT go blank! It continues displaying the active Operator Run screen so operators can physically assist with product adjustments, lens wiping, or lead screws with live camera feedback.
  • Service Console on Private Browser: The remote engineer sees the full engineering tools on their private screen, while factory floor observers see only the clean Operator view with generic DIN/IEC labels (Position 1, 2D Code).
  • Line Database Security (REQ-16): Database file is encrypted on disk (AES-256-GCM via DPAPI & TPM 2.0) and owned by NT SERVICE\SundaramVisionSvc. Operators are explicitly denied NTFS access; zero cleartext passwords exist. Cryptographic HMAC hash chain detects manual DB tampering and fails closed.

Notification Dictionary & Auto-Localization Engine (REQ-13)

  • Fixed OEM Authoring: OEM hardcodes notifications once in the master dictionary with actionable shop-floor guidance (e.g. "Turn Lead Screw X by 1.85 turns CCW"). Customer supervisors do not edit text.
  • Automatic Multi-Language Localization: Built-in verified localizations across plant languages (English, हिन्दी, ગુજરાતી, தமிழ்) with 1-click line language switching.

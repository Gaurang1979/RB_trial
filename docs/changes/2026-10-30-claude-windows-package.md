## Decisions (section 4)
| Windows engine build | The C++ engine is built with MSVC on Windows only (build-windows.bat), not cross-compiled on macOS. No clang-cl, zig or mingw toolchain is installed here; a mingw or zig build of OpenCV through vcpkg would be a different compiler from the one the engine tests and the bench baseline run on, and it could not be run or tested on this Mac. The .NET programs cross-publish for win-x64 from macOS. | 13 |
| Engine C runtime on the line PC | The engine DLLs use the dynamic C runtime (x64-windows-static-md); the package copies the Visual C++ runtime DLLs next to them (app-local, allowed by the redistributable licence), so the line PC needs no VC++ runtime install. | 13 |
| Test build without licence | Owner, 2026-10-30: the Windows test build has the licence check off (Studio:LicenceRequired=false, written by first-run setup); licensing and the signed Vision Package stay deferred. | 10 |
| Pre-install check before the vision software | Owner, 2026-10-30: "all supporting software with version verification required to run this project must be first checked, installed and then only vision software to be installed. check all hardware capabilities and working/installation space also." The installer runs preflight.ps1 in PrepareToInstall (Setup.bat runs it first too): a FAIL stops before any file is copied. Hikrobot MVS is the one supporting component installed by it, only from a validly Hikrobot-signed installer (and a matching SHA256SUMS.txt line when given); .NET and the VC++ runtime travel in the package, ONNX Runtime is not used. Limits (estimates until #148 measures 225 per minute on Windows): 4 cores, 8 GB, 15 GB free refused below; 8 cores, 16 GB, 100 GB, SSD, one port per GigE camera plus the PLC, jumbo frames, 1366x768 warned below. The rules are pure functions tested with Pester on any PC. | 11 INS-01 to INS-05 |
| Owner test build, not a customer release | The package is for the owner's own Windows test PC (INS-06). The customer-release protection (CLAUDE.md protection rules 2, 3 and 5, requirements section 18) is not built into the code yet: .NET still loads each tool DLL by name, models are plain ONNX on main (#222 open), there is no anti-tamper runtime (#263 open), and there is no AOT, single-file or signing. So the build copies what main has, marks VERSION.txt "Owner test build, not for customer PCs", and the guide says not to install it on a customer PC. | 11 INS-06, 18 |
| Teach app with the runtime service | The teach app (dotnet/VisionStudio, web) ships with the package for making jobs and PLC settings until Vision Studio has those screens; it answers on 127.0.0.1:5090 only, shares the jobs and data folders, and Teach.bat stops the vs-runtime service while it runs, because the cameras and port 502 belong to one program at a time. | 12 |

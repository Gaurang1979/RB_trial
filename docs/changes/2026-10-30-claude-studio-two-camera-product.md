## Decisions (section 4)
| Job designer access | Only Engineer and Admin in Vision Studio may read, try and save whole jobs (new rule RuntimeAccess.MayDesignJobs); Supervisor and QA keep MayChangeSetup for what comes later. A browser or plant token never designs. | UI-UX-SPEC 4.7; ARCHITECTURE 2.2 |
| A job travels as its file's JSON | GetJob/SaveJob/TryJob carry the job file (JOB-FILE-FORMAT.md) as JSON and Studio edits it in place, so settings Studio does not show are kept; the runtime checks every save with Job.Validate, refuses a PLC number another job has, and refuses saving the running job while the line runs. | requirements 12 |
| Nothing is tried while the line runs | TryJob is refused while the line runs: building tools and reading full pictures would take the CPU the parts need. | requirements 12 |
| OpenCV threads during a decode | decode() no longer calls cv::setNumThreads (process-wide; with the TBB backend it re-creates the arena under any other thread's parallel_for_, which crashed vs-runtime when the text tool of another camera ran at the same time). A helper thread holds a one-item parallel region open while the passes run, which keeps OpenCV from fanning out inside them, as before, without the crash. | requirements 12 |
| Job menu in the designer | Owner, 2026-10-30, through the UI/UX session: "Job saving and reload option also required", in this PR. Save as saves the draft as a new job with the PLC number cleared (two jobs with one number would leave the PLC's choice to chance); Reload and opening another job ask "Drop the changes since the last save?" when the draft differs from the saved job; the designer opens on the line's job; after a restart the line loads its last job as before (Station, last-job.txt). | UI-UX-SPEC 4.7; requirements 8 |
| Live frames of every camera | WatchFrames.all_cameras sends every camera's frames (rate cap per camera); a bad part's frame is never held back by the rate cap, so the Run screen shows every bad part's picture. Start batch is a toolbar action with F3 beside Change product (after #183's compact toolbar); camera chips sit over the live image. | UI-UX-SPEC 4.1 |

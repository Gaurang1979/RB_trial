Machine ON ≠ machine producing

A powered machine can be idle, waiting, blocked or bypassed. The platform tells them apart.

POWERED ON

Power is on. On its own this says nothing about production.

RUNNING

The machine reports a running signal.

PRODUCING

Cycles are completed and output is counted.

STARVED

Stopped because the upstream machine has no material to give.

BLOCKED

Stopped because the downstream machine cannot accept output.

BYPASS SUSPECTED

Running signal on, but no cycles. Reported as a signal inconsistency, with evidence.

Also detected: fault, idle, sensor malfunction, communication loss, no data from a gateway.

2

This is the core idea. Ask the room how many of their machines show green on a screen while producing nothing. Bypass is always reported neutrally as a signal inconsistency, never as an accusation.
